This explorer supports discussion about VCSE prevention grants. It describes populations within neighbourhoods; it does not identify individuals, diagnose hypertension or estimate undiagnosed hypertension. Population groups overlap. Area totals are not counts of unique eligible beneficiaries.

01 · Population

ONS small-area estimates via Nomis, dataset NM_2014_1 (PESTOA2021), mid-2024. API variables: gender=0,c_age=0 for all residents; gender=1,c_age=141…175 for the 35 single ages 40–74 inclusive; measures=20100. Men’s percentage divides by the total MSOA population.

02 · Ethnicity

Census 2021 TS021, Nomis NM_2041_1, Census Day 21 March 2021. Ethnic minority means all residents excluding White: English, Welsh, Scottish, Northern Irish or British. It includes other White groups. Total category 0 minus category 1; non-White subtracts categories 1–5 from total. Nineteen mutually exclusive constituent categories are retained. These broad groupings contain diverse communities.

03 · Deprivation

English Indices of Deprivation 2025, File 7. Sum its mid-2022 total population for 2021 LSOAs in national IMD deciles 1 and 2; divide by the total corresponding LSOA population in each MSOA. All 860 South Yorkshire LSOAs are included once, using the ONS exact-fit OA→LSOA→MSOA lookup, deduplicated to LSOA. The targeting measure remains unchanged. A separate population-weighted average IMD score is also supplied for descriptive comparison; it is not used to decide any targeting flag.

04 · Targeting rules

For each of 171 South Yorkshire MSOAs, compare deprivation %, ethnic minority % and men aged 40–74 count with the selected percentile. The default top 20% uses the 80th percentile with linear interpolation: sorted position (n−1)×0.8. All ties at or above the cutoff are included, so the selected share may exceed 20%. Place and search filters never change thresholds.

ANY requires at least one selected flag; ALL requires every selected flag. No selected criteria means no matches. Map and bubble colours show the number of selected criteria met. The all-three KPI always tests the three original flags. The number/percentage control changes only the men aged 40–74 table column. Deprivation and ethnicity remain percentages in the shortlist. It never changes targeting criteria or thresholds.

05 · Emergency admissions

OHID Local Health, indicator 93227, “Emergency hospital admissions: all causes”. Latest returned published period: 2016/17–2020/21. All ages, persons; indirectly age-standardised admission ratio (observed ÷ adjusted expected admissions × 100), with England = 100. Values and 95% confidence limits are retained at source precision. It reflects hospital use and many influences, not undiagnosed hypertension. The period includes the start of the COVID-19 pandemic.

The source uses 2011 MSOAs. The ONS exact-fit 2011→2021 correspondence confirms 170 unchanged areas (change code U); these are carried forward. E02007002, Wickersley South, Bramley South & Whiston, merges E02001599 and E02001601. Its SAR is unavailable: observed and expected counts are not published, so averaging SARs or weighting them by population would be unjustified. It is excluded from no targeting criteria because admissions is contextual only.

06 · Geography & names

All 171 2021 MSOAs: Barnsley 30, Doncaster 39, Rotherham 32 and Sheffield 70. Commons Library names v2.3, 13 February 2026, provide recognisable neighbourhood labels; original ONS names and MSOA21CD remain available. These names are descriptive, not formal administrative neighbourhood boundaries.

ONS December 2021 BGC V3 boundaries are generalised for display and retrieved in WGS84 with five decimal coordinate precision and additional 0.00015-degree simplification. The map is for targeting discussion, not address allocation.

Validation and limitations

All core joins, unique codes, 35 male ages per MSOA, ethnicity category totals, numeric ranges, 860 LSOA mappings and 171 boundaries passed automated checks. Mid-2024 population sums match the four published Nomis local-authority totals exactly: Barnsley 251,770; Doncaster 319,765; Rotherham 276,595; Sheffield 582,493. South Yorkshire total: 1,430,623. Default targeting flags: 77 ANY; 3 ALL. Details are in QA.md and qa.json.

Different reference periods are intentional and clearly labelled. Census disclosure control can cause small inconsistencies, although the 19 ethnicity categories sum exactly to the published total in every included MSOA in this snapshot. Population estimates are estimates, not exact headcounts. A high count can reflect a larger area; a high percentage reflects population composition. Thresholds are a transparent planning choice, not evidence of programme effectiveness. The deprivation measure characterises LSOAs, not the deprivation status of every resident.

All charts, tables and exports use the same filtered rows. Grey map shapes provide geographical context outside the filters. Selecting an area highlights it and opens details without altering the cohort; “Filter to this area” explicitly applies a code filter and shows it even if it does not match the targeting rule. Comparison selections persist across filters. KPI population sums include only matching areas in the current view. Area Explorer can inspect any area. The denominator in the matching-neighbourhoods KPI includes every MSOA in the selected geography, even when search or health filters narrow the numerator.

Browser visual and responsive-layout QA could not be performed in this session because the supported browser preview was unavailable. Automated data, logic and DOM interaction checks are documented separately; a local browser acceptance checklist is supplied.

Supplementary average IMD 2025 score

For each MSOA, calculate sum(LSOA IMD 2025 score × supplied mid-2022 LSOA population) / sum(supplied mid-2022 LSOA population). All constituent LSOAs contribute, not only deciles 1–2. The reproducible output is msoa_imd_scores.csv; the LSOA audit file retains each underlying score and weight. This is a local descriptive aggregation of the official LSOA scores, not an official MSOA index or national rank. Scores are not percentages, and a score twice as large does not establish twice the deprivation.

The concentration percentage asks “How many residents live in the nationally most deprived fifth of neighbourhoods?” The weighted score describes deprivation across the entire MSOA, including LSOAs outside that fifth, and can distinguish areas sharing a concentration of 0% or 100%. Neither measure describes every individual resident.

Switching the quadrant X-axis does not change the shortlist or flags. The percentage view uses the original deprivation cutoff. The score view uses the fixed South Yorkshire population-weighted mean score (29.1100322876 in this snapshot) as a descriptive benchmark, independent of Place and analyst percentile settings. It is not the deprivation targeting threshold. The horizontal line continues to use the ethnic minority percentage cutoff. Higher/lower quadrant labels describe positions relative to the displayed lines. In score mode the upper-right area is labelled as two measures above their reference lines, not automatically two targeting flags.

Admissions as additional context

The admissions KPI counts shortlisted areas with SAR strictly greater than 100, among those with a non-missing value. It always uses England=100, even if the optional filter threshold is changed. It reports data availability against the full current shortlist. It does not indicate statistical significance; no confidence-interval test is used. No South Yorkshire-wide SAR is calculated.

The separate health filter can highlight areas with SAR strictly above an analyst-selected value, or restrict the displayed rows to them. Highlight mode changes no totals. Restrict mode excludes missing values and changes the shortlist, KPI totals and population breakdown. Neither mode changes any population flag or adds a fourth criterion. Reset restores the default top 20%, all three criteria, at-least-one rule and no health restriction.

The admissions map uses a continuous diverging scale anchored at 100, with endpoints 0 and 200. Values above 200 share the end colour, labelled “200+”; exact values remain in tooltips. Hatched polygons mean missing admissions data; pale grey polygons are outside the current filters. Replacement CSVs refresh the period labels, map, tooltips, KPI and filter automatically.

KPI and population-breakdown definitions

All cards summarise neighbourhoods that meet the population rule and current Place, search and any health restriction. The all-three card counts those meeting all three original demographic flags, even if fewer criteria are selected in the sidebar. It describes overlapping area characteristics, not residents who personally belong to all three groups. When “Show matching areas only” is unchecked, nonmatching areas appear as context but do not contribute to the shortlist KPIs.

The secondary row separately sums deprived-LSOA residents (IMD 2025, mid-2022 weights), ethnic minority residents (Census 2021) and men aged 40–74 (mid-2024). The groups overlap and use different reference periods; never add them to estimate unique people. The residents KPI includes everyone in shortlisted MSOAs, using mid-2024 estimates.
