# GitHub Pages update — table shading and header

Extract the ZIP and open the south-yorkshire-explorer folder. Replace these three files alongside the existing index.html in your GitHub Pages repository:

- index.html
- refinements.js
- styles.css

Replace all three together. Do not upload the ZIP itself or nest an extra project folder. No build step is needed. After GitHub Pages finishes updating, refresh with Ctrl+F5.

The header now identifies NHS South Yorkshire ICB · Data & Analytics · Population Health. Only qualifying values in the three population columns receive pale blue-grey shading and stronger text weight. The legend updates for custom targeting percentages. Admissions and criteria badges retain their existing styling.

All other application files, datasets, processing scripts and calculations are unchanged from the preceding version. Preserve any newer admissions CSV you have installed. The complete project is included for convenience.
